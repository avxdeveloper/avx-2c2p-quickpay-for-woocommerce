## ✨ Overview

AVX 2C2P QuickPay for WooCommerce enables merchants to generate payment links for WooCommerce orders, including checkout payments and links shared with another payer. Signed payment notifications can update WooCommerce order information. Card information is entered at the 2C2P-hosted gateway, not directly in this plugin.

## ⚙️ Key Features

- WooCommerce Classic Checkout and Checkout Blocks
- Test and Live payment modes
- WooCommerce HPOS support
- Optional percentage-based payment fee
- Payment-link expiration handling
- Manual payment-link attachment to orders
- Signed payment notifications, order statuses and order notes

## 🧩 Requirements

WordPress, WooCommerce, an eligible **2C2P merchant account with QuickPay API access**, and an accessible HTTPS notification endpoint for live operation.
